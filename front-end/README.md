# NexStore Demo

Frontend demonstrativo em React + Vite.

## Como executar

1. Abra esta pasta no terminal.
2. Execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço local exibido pelo Vite.

## Observações

- O login e o cadastro são simulados no frontend; não há API ou banco de dados conectado.
- Para entrar, informe qualquer nome de usuário e uma senha com pelo menos 4 caracteres.
- Todos os produtos, preços, avaliações, frete e compras são fictícios. Nenhuma cobrança ou entrega real acontece.
- As formas de pagamento exibidas são somente cartão de crédito, cartão de débito e Pix.
